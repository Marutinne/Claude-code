# 執筆ガイド：『ファンダメンタルズ投資完全読本』

あなたはこの本の1章（または数章）を書く執筆者です。読者は日本の個人投資家で、ゼロから学び始めて、最終的にプロのアナリストに近い水準まで到達したい人です。本は Web 書籍（`index.html` が目次と本文の枠を持ち、各章は `chapters/<id>.html` を読み込んで表示）です。

## 1. 守ること（最重要）

- **正確さが最優先**。不確かな数字・制度・年号・人物の発言は書かない。分からないことは「〜とされる」と逃げるのではなく、書かないか、確認してから書く。架空の統計・論文・URL・引用を作らない。
- **時期で変わる情報**（会計基準の適用時期、東証の要請、開示制度、市場の慣行など）は WebSearch で確認してから書き、本文に「2026年11月時点」などの時点を添える。検索は1章あたり5回程度までにとどめる。基礎的で変わらない内容（会計の仕組み、公式など）は検索不要。
- **計算はすべて実際に計算してから書く**。本文・表の数値は `python3 -c` などで検算する。図（折れ線・棒など）と試算ツールはページ上で計算されるので、本文の数値と一致させる。
- **数値例は架空企業で行う**。実在企業の名前は、記録の確かな歴史的事例（粉飾事件、著名な買収など）と制度の説明にだけ使う。架空企業は「A社」「架空の○○株式会社」など明らかに架空と分かる名前にする。本書の通し例「ミナモ精機」は下の数値表から外れない。
- **特定銘柄の売買推奨はしない**。
- 編集してよいのは自分の担当ファイル `chapters/<id>.html` だけ。`assets/`、`index.html`、他の章、`tools/` は変更しない。

## 2. 文体

- です・ます調。平易で正確に。1文は短めに。専門用語は初出で定義し、必要なら英語を括弧で添える（例：株主資本コスト（Cost of Equity））。
- 説明の型：**考え方 → 数値例 → 読み方・使い方 → 落とし穴**。抽象論だけで終わらせない。
- 応用編（Lv.3〜4）は、プロの実務で使う論点・数式・調整項目まで踏み込む。「入門書では省略されがちな点」を積極的に扱う。
- 数字は半角、単位を必ず付ける（億円・円・%・倍・日・年）。％ではなく半角 %。用語は「」、書名は『』。
- 絵文字・顔文字は使わない。「〜しましょう！」のような煽りはしない。
- 他章への参照はリンクにする：`<a href="#ch14-3">第14章 14-3</a>`、章全体なら `<a href="#ch14">第14章</a>`。

## 4. 使える部品

### 囲み
```html
<div class="box key"><span class="box-label">ポイント</span><p>…</p></div>
<div class="box warn"><span class="box-label">注意</span><p>…</p></div>
<div class="box tip"><span class="box-label">実践のコツ</span><p>…</p></div>
<div class="box example"><span class="box-label">数値例</span><p>…</p></div>
<div class="box case"><span class="box-label">事例</span><p>…</p></div>
<div class="box formula"><span class="box-label">公式</span><p class="eq">ROE ＝ 当期純利益 ÷ 自己資本</p><p>記号の説明…</p></div>
<details class="deep"><summary>深掘り：…（読み飛ばしても可）</summary><div><p>…</p></div></details>
```

### 表（横にはみ出してもスクロールできる）
```html
<div class="tbl"><table>
<caption>単位：億円</caption>
<tr><th>項目</th><th class="r">2025年3月期</th></tr>
<tr><td>売上高</td><td class="r">452.0</td></tr>
<tr><td class="ind">うち海外</td><td class="r">…</td></tr>
<tr class="sum"><td>営業利益</td><td class="r neg">-3.0</td></tr>
</table></div>
```
`r`＝右寄せ、`neg`/`pos`＝赤/緑、`ind`＝字下げ、`tr.sum`＝合計行。

### 手順・比較
```html
<ol class="flow"><li>手順1の説明</li><li>手順2</li><li>手順3</li></ol>
<div class="compare"><div><h4>A</h4><p>…</p></div><div><h4>B</h4><p>…</p></div></div>
```

### 図（ページ上で描画。JSON を含む属性は必ずシングルクォート）
共通：`data-title`（図の題）、`data-caption`（図の下の注記）。書式 `fmt` 系：`pct`（0.12→12.0%）, `pct0`, `pct2`, `x`（倍）, `x2`, `yen`（円）, `oku`（億円）, `oku1`, `num0`〜`num2`, `yr`（年）。

**折れ線（時系列）**
```html
<div class="linechart" data-title="売上高と営業利益" data-x="22/3期,23/3期,24/3期" data-yfmt="oku"
  data-series='[{"name":"売上高","values":[400,432,410],"labels":true},{"name":"営業利益","values":[50,58.3,41],"color":"accent"}]'></div>
```
**折れ線（関数）**：x の範囲で式を描く。式では x・`data-vars` の変数・下の関数が使える。
```html
<div class="linechart" data-title="理論PER" data-xrange="0,0.07" data-xfmt="pct" data-xlabel="成長率" data-yfmt="x"
  data-vars='{"r":0.08}' data-series='[{"name":"ROE 15%","expr":"per(0.15,r,x)"}]' data-hlines='[{"y":12.5,"label":"1/r"}]'></div>
```
オプション：`data-ymin` `data-ymax` `data-zero="0"`（0を含めない） `data-points="0"` `data-vlines='[{"at":2,"label":"…"}]'`（関数モードは `"x"`）。色：`"color":"accent|teal|orange|gain|loss|muted|fg"`、破線 `"dash":true`。

**棒**
```html
<div class="barchart" data-title="営業利益率" data-labels="自社,A社,B社" data-yfmt="pct"
  data-series='[{"values":[0.145,0.11,-0.02]}]' data-highlight="0"></div>
```
複数系列は並べて表示、`data-stacked="1"` で積み上げ。`data-values="0"` で値ラベル非表示。

**ウォーターフォール（横向き。売上→利益、時価総額→EV、価値の積み上げ等）**
```html
<div class="waterfall" data-title="売上高から営業利益へ" data-fmt="oku1"
  data-steps='[{"label":"売上高","value":488,"total":true},{"label":"売上原価","value":-319.6},{"label":"売上総利益","total":true},{"label":"販管費","value":-97.6},{"label":"営業利益","total":true}]'></div>
```
`total:true` で value を省略すると、それまでの累計を小計として表示。

**散布図**
```html
<div class="scatter" data-title="ROEとPBR" data-xfmt="pct" data-yfmt="x" data-xlabel="ROE" data-ylabel="PBR" data-fit="1"
  data-points='[{"x":0.05,"y":0.7,"label":"A社"},{"x":0.14,"y":2.4,"label":"ミナモ精機","color":"orange"}]'></div>
```
`data-fit="1"` で回帰直線と決定係数を表示。

**感度分析表（2変数の表を計算して色分け）**
```html
<div class="sens" data-title="1株価値の感度" data-rowvar="r" data-rows="0.07,0.08,0.09" data-colvar="g" data-cols="0.005,0.01,0.015"
  data-vars='{"fcf":37.7,"net":-46.7,"sh":48.52}' data-expr="(dcf(fcf,0.05,5,g,r)-net)*100/sh"
  data-fmt="yen" data-rowfmt="pct" data-colfmt="pct" data-base="0.08,0.01" data-rowlabel="割引率" data-collabel="永久成長率"></div>
```
`data-compare="1800"` を付けると、その値（例：現在株価）より高い/低いで色分け。

**試算ツール（スライダーで前提を動かす。応用章では積極的に使う）**
```html
<div class="calc" data-title="理論PBR" data-caption="g < r の範囲で計算"
  data-inputs='[{"id":"roe","label":"ROE","min":0,"max":0.25,"step":0.005,"value":0.12,"fmt":"pct"},
                {"id":"r","label":"株主資本コスト","min":0.04,"max":0.12,"step":0.0025,"value":0.08,"fmt":"pct2"}]'
  data-vars='{"g":0.02}'
  data-outputs='[{"label":"理論PBR","expr":"pbr(roe,r,g)","fmt":"x2","hl":true},{"label":"理論PER","expr":"per(roe,r,g)","fmt":"x1"}]'></div>
```

**式で使える関数**（JavaScript の式。`Math.pow` なども可）
- `pv(r,n,fv)` 現在価値、`fv(r,n,pv)` 将来価値、`annuity(r,n)` 年金現価係数
- `npv(r,[cf1,cf2,…])`（cf1 は1年後）、`irr([cf0,cf1,…])`（cf0 は現在、通常マイナス）
- `gordon(cf1,r,g)` ＝ cf1/(r−g)
- `dcf(fcf0,g1,n,g2,r)`：直近FCF fcf0 が n 年間 g1 で成長、その後 g2 で永久成長、割引率 r の現在価値合計（企業価値）。`tvshare(...)` はそのうちターミナルバリューの比率
- `rim(b0,roe,r,g)` 残余利益モデル（定常状態）、`pbr(roe,r,g)`＝(ROE−g)/(r−g)、`per(roe,r,g)`＝(1−g/ROE)/(r−g)
- `capm(rf,beta,mrp)`、`wacc(E,D,re,rd,t)`、`cagr(a,b,n)`、`kelly(p,b)`、`clamp(x,a,b)`、`sum([…])`

### 自作の図（SVG）
概念図は `<figure class="fig"><div class="fig-svg"><svg viewBox="0 0 600 240" role="img" aria-label="…">…</svg></div><figcaption>…</figcaption></figure>`。色は `var(--fg)` `var(--muted)` `var(--accent)` `var(--gain)` `var(--loss)` `var(--line)` `var(--surface)` だけを使う（ダークモード対応のため）。文字は `font-size="12"` 以上、幅 600 以内。スマホでは縮小表示されるので文字は多くしない。
