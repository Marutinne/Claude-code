# 執筆ガイド（各章の本文を書くときの共通ルール）

読者：オプション取引の完全初心者（日本居住者）。目標は「完全に・全て」マスターすること。
全体構成：`00_枠組み.md`。表示サイト：`site/`（`site/index.html` が章ファイルを読み込んで表示する）。

## ファイル
- 各章は `site/chapters/<章ID>.html` に **HTML の断片** として書く（`<html>` `<head>` `<body>` `<style>` `<script>` は書かない）。
- 章ID：`ch00`〜`ch25`、`ex1`〜`ex4`、`hist`、`stories`、`qa`、`glossary`、`cheatsheet`、`formulas`、`refs`。
- 見出しの `id` は `<章ID>-<番号>`（例 `ch03-2`）。他章へのリンクは `<a href="#ch05">第5章</a>`、節へは `<a href="#ch05-3">`。

## 章の骨格（この順番）
```html
<header class="chapter-head">
  <p class="eyebrow">第1部　ゼロから学ぶ基礎</p>
  <h1>第3章　損益図の読み方 <span class="lv">Lv.1</span></h1>
  <p class="lead">1〜2文の導入。</p>
</header>
<div class="box goal"><span class="box-label">この章で分かること</span><ul><li>…</li></ul></div>
<h2 id="ch03-1">3-1　…</h2> …本文…
<h2 id="ch03-9">まとめ</h2><ul class="summary-list"><li>…</li></ul>
<div class="quiz"> …確認テスト… </div>
```

## 使える部品
| 部品 | 書き方 |
|---|---|
| 重要ポイント | `<div class="box key"><span class="box-label">ここが重要</span><p>…</p></div>` |
| 注意 | `<div class="box warn"><span class="box-label">注意</span>…</div>` |
| 実践テクニック | `<div class="box tip"><span class="box-label">実践テクニック</span>…</div>` |
| 数値例 | `<div class="box example"><span class="box-label">数値例</span>…</div>` |
| 深掘り（数式など） | `<details class="deep"><summary>深掘り：…</summary><div>…</div></details>` |
| 表 | `<div class="tbl"><table>…</table></div>`（数値セルは `class="r"`） |
| 手順図 | `<ol class="flow"><li><b>見出し</b><br>説明</li>…</ol>`（STEP番号は自動） |
| 左右比較 | `<div class="compare"><div><h4>…</h4>…</div><div>…</div></div>` |
| 自作の図 | `<figure class="fig"><div class="fig-svg"><svg viewBox="…">…</svg></div><figcaption>…</figcaption></figure>`（色は `var(--fg)` `var(--muted)` `var(--line)` `var(--accent)` `var(--gain)` `var(--loss)` `var(--gold)` `var(--surface)` のみ。文字は `fill="var(--fg)"`。全図形に fill を明示） |

### 損益図（自動計算・自動描画）
```html
<div class="payoff" data-title="カバード・コール" data-spot="100" data-range="70,130"
     data-legs='[{"type":"stock","qty":1,"price":100},{"type":"call","k":105,"qty":-1,"prem":2.5}]'
     data-curves="30,10" data-caption="説明文"></div>
```
- `type`: `call` / `put` / `stock`（stock は `price` が取得価格）。`qty` 正=買い、負=売り、2 なら2枚。`prem` は1単位あたりプレミアム。
- `data-curves="30,10"`：満期前（残り30日、10日）の損益曲線を破線で追加（ブラック・ショールズで計算、`data-iv` 既定0.2）。
- 満期の異なる戦略（カレンダー等）は各レッグに `"dte":30` / `"dte":60`。
- 日経225オプションの実額表示は `data-mult="1000"`（ミニは100、米国株は100）。米国の例は必ず `data-unit="ドル"` を付ける（付けないと縦軸が「円」になる）。
- 確認テストで答えを隠すときは `data-hide="legs,stats,be"`（レッグ名・統計・損益分岐点ラベルを非表示。`data-title` も答えにならないものにする）。
- 最大利益・最大損失・損益分岐点は自動計算されて図の下に出る。**本文の数値と必ず一致させる**（プレミアムは現実的な値に）。

### グリークス・価格曲線（自動描画）
```html
<div class="greek" data-greek="delta" data-type="call" data-k="100" data-iv="0.2" data-days="60,30,7" data-range="70,130"></div>
<div class="greek" data-greek="value" data-type="call" data-k="100" data-days="90,30,0" data-intrinsic></div>
<div class="greek" data-greek="decay" data-type="call" data-spot="100" data-ks="100,110" data-maxdays="90"></div>
```
`data-greek`：`value` 価格／`timevalue` 時間的価値／`delta`／`gamma`／`theta`（1日あたり）／`vega`（IV1%あたり）／`prob`（満期ITM確率の目安）／`decay`（残り日数に対する価格の減少）。`data-title` `data-caption` 任意。

### 確認テスト
```html
<div class="quiz"><p class="quiz-title">確認テスト</p>
  <div class="q"><p>問題文</p>
    <ol class="choices"><li>…</li><li>…</li></ol>
    <details><summary>解答と解説</summary><div><p><b>正解：B</b>　解説…</p></div></details>
  </div>
</div>
```
Q番号・選択肢記号(A)(B)…は自動。計算問題・損益図を読む問題（問題内に `.payoff` を置いてよい）も入れる。1章あたり6〜10問。

## 文章のルール
- です・ます調。1文を短く。専門用語は初出で「日本語（英語）」＋一言説明。
- 抽象論の直後に必ず具体的な数値例を置く。日本の例（日経225）と米国の例（個別株・SPY等）を両方使う。
- 「なぜそうなるか」を必ず説明する。暗記に頼らせない。
- 「裏技」は違法・脱法ではなく、実務で使われる合法的な工夫として書く（`box tip`）。
- 制度・税・手数料・証券会社のサービスは変わりうるので、断定しすぎず「執筆時点（2026年）」と明記し、確認先（JPX、国税庁、各証券会社）を示す。自信のない固有の数値は書かない。
- 投資の推奨はしない。売り戦略のリスク（損失が大きくなりうること）は毎回明記。
- 絵文字は使わない。見出しに記号装飾をしない。
- 分量の目安：1章あたり本文 8,000〜15,000字、図 4〜10点。

## 戦略の書き方（第3部以降、各戦略で必ずこの順番・この見出し）
各戦略は `<h2 id="chNN-k">NN-k　戦略名（英語名）</h2>` とし、次の構成で書く。
```html
<div class="tbl"><table>
<tr><th>相場観</th><td>強気／弱気／中立／大きく動く など</td></tr>
<tr><th>組み方</th><td>例：原資産100株買い＋OTMコール1枚売り</td></tr>
<tr><th>最大利益</th><td>式と数値例</td></tr><tr><th>最大損失</th><td>式と数値例</td></tr>
<tr><th>損益分岐点</th><td>式と数値例</td></tr>
<tr><th>デビット／クレジット</th><td>…</td></tr>
<tr><th>主なグリークス</th><td>デルタ＋、ガンマ−、セータ＋、ベガ− など</td></tr>
<tr><th>難易度</th><td>★☆☆〜★★★</td></tr>
<tr><th>日本で可能か</th><td>日経225オプション／ミニで可能か、個別株では現実的か</td></tr>
<tr><th>米国で可能か</th><td>個別株・ETF・指数で可能か、必要な口座レベルの目安</td></tr>
</table></div>
```
続けて h3 で：「しくみ」（損益図 `.payoff`、必要なら `data-curves`）→「メリット」→「デメリット・リスク」→「向いている相場・向かない相場」→「建てた後の管理と調整」→「実践テクニック」（`box tip`）→ 必要なら「日経225での実額例」（`data-mult="1000"`）。
- 数値例は原則「株価100、IV20%、残り30日」を基準にし、プレミアムは book.js の bs() で計算した現実的な値を使う（node で計算）。
- 似た戦略との違い（例：カラーとフェンスの違い）を必ず比較表で示す。
- 章の最後に「この章の戦略早見表」（全戦略を1表：相場観・最大利益・最大損失・難易度・日米可否）を置く。
