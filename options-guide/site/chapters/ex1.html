第1問　用語と仕組み（15点）

基本用語を「なんとなく」ではなく、正確に使い分けられるかを確かめます。

第1問　用語と仕組み（5問・15点）

次のア〜エのうち、正しい記述の組み合わせはどれですか。（3点）
ア：プットの売り手は、買い手が権利を行使すると、原資産を権利行使価格で買い取る義務を負う。
イ：コールの買い手の最大損失は、原資産が大きく下がると無制限になる。
ウ：満期時のコールの価値は「原資産価格−権利行使価格」とゼロの大きい方で、マイナスにはならない。
エ：オプションの売り手は、損が出そうになったら義務を放棄して取引を終えられる。

  1. ア・イ
  2. ア・ウ
  3. イ・エ
  4. ウ・エ
解答と解説

正解：B（3点）　アは正しい記述です。プットは「売る権利」なので、買い手が権利を使うと、売り手は権利行使価格で原資産を買い取る側になります。ウも正しい記述です。満期に原資産が権利行使価格より安ければ、コールの買い手は権利を使わずに捨てればよいので、価値はゼロより下がりません。

イは誤りです。コールの買い手は、どれだけ下がっても権利を放棄すればよく、損失は支払ったプレミアムまでです。エも誤りです。放棄できるのは権利を持つ買い手だけで、売り手が抜けたいときは同じオプションを買い戻します。この「選べるのは買い手だけ」という非対称性が、買いは損失限定、売りは利益限定という損益の形を生みます。関連：1-2 コールとプット、1-3 買い手と売り手の非対称性

日経平均が40,250円のとき、次の日経225オプションのうち、本質的価値が最も大きいものはどれですか。（3点）

  1. 権利行使価格39,750円のコール
  2. 権利行使価格40,875円のプット
  3. 権利行使価格40,125円のコール
  4. 権利行使価格41,000円のコール
解答と解説

正解：B（3点）　本質的価値は「いま権利を使ったら得をする額」です。コールは「日経平均−K」、プットは「K−日経平均」で、マイナスならゼロです。

(A) 40,250−39,750＝500円、(B) 40,875−40,250＝625円、(C) 40,250−40,125＝125円、(D) 41,000円で買う権利は得をしないのでOTMで0円です。コールだけを見て「権利行使価格が低いほど大きい」と考えると(A)を選んでしまいます。プットは権利行使価格が高いほど本質的価値が大きくなる点がポイントです。なお、プレミアム全体の大小は時間的価値も加わるので、本質的価値の大小とは一致しないことがあります。関連：2-5 ITM・ATM・OTM、2-6 本質的価値と時間的価値

Aさんはある日経225プットを1枚買い建てていて、今日それを市場で売って手じまいました。Bさんは同じ銘柄のプットを1枚売り建てていて、今日それを市場で買って手じまいました。この2つの注文が互いの相手として約定したとき、取引の呼び名（Aさん・Bさんの順）と、市場全体の建玉の変化の組み合わせとして正しいものはどれですか。（3点）

  1. 転売・買戻し。建玉は1枚減る
  2. 転売・買戻し。建玉は変わらない
  3. 売り建て・買い建て。建玉は1枚増える
  4. 買戻し・転売。建玉は1枚減る
解答と解説

正解：A（3点）　買いの建玉を売って閉じるのが「転売」、売りの建玉を買って閉じるのが「買戻し」です。どちらも新規ではなく返済の注文です。返済どうしが約定すると、その契約は市場から消えるので、建玉（オープン・インタレスト）は1枚減ります。出来高は1枚増えます。

新規どうしなら建玉は1枚増え、新規と返済なら建玉が持ち主を変えるだけで変わりません。(C)は新規の呼び名で、手じまいには使いません。関連：2-9 建玉と出来高、新規と返済

米国株で「高い権利行使価格のプットを売り、低い権利行使価格のプットを買う」2本組みの取引をしたいのですが、使っている証券会社がコンボ注文（全レッグを1つの差し引き価格で発注する注文）に対応していません。1本ずつ発注する（レッギング）ときの考え方として、本書の説明に最も合うものはどれですか。（3点）

  1. 受取を先に確保するため、売りのプットから先に約定させる
  2. 買いのプットを先に約定させてから売りのプットを出す。売りだけが約定した無防備な状態で急変に遭うのを避けるため
  3. 2本とも成行で同時に出せば、コンボ注文と同じ結果になる
  4. どちらを先にしても、リスクは変わらない
解答と解説

正解：B（3点）　レッギングでは、1本目と2本目の間に相場が動きます。売りが先に約定して買いがまだのときに急落すると、損失の上限がない「裸のプット売り」を抱えたことになります。だから、リスクを減らす側（ここでは買い）から先に建てるのが定石です。決済するときは逆に、売りのレッグから先に買い戻します。

(C)は誤りです。成行は薄い板で不利な価格まで約定が進むことがあり、2本が同時に約定する保証もありません。コンボ注文が「全部約定するか、何も約定しないか」になるのとは違います。関連：6-2 注文の出し方、6-3 板の薄さとビッド・アスク・スプレッド

次の説明と用語の組み合わせのうち、正しいものはどれですか。（3点）

  1. 満期に原資産が、売っているオプションの権利行使価格ちょうど付近で終わり、割り当てられたかどうかを週明けまで確実に知れない ―― ピン・リスク
  2. 配当落ち日の前日に、ITMのコールの売り手が割り当てられる ―― IVクラッシュ
  3. 最終取引日の翌朝、日経平均の構成銘柄それぞれの始値から算出される清算用の値 ―― 日経平均VI
  4. 評価損や必要額の増加で預けた証拠金が不足し、追加の入金を求められる ―― ロスカット
解答と解説

正解：A（3点）　ピン・リスクは、米国株オプションのように現物受渡しのオプションで特に問題になります。割り当てられなければ、思っていなかった100株のポジションを持ったまま週末を越えることがあります。

(B)は早期割当の説明です。IVクラッシュは決算などのイベント後にIVが急低下することです。(C)はSQ値（特別清算指数）の説明で、日経平均VIは日経225オプションの価格から計算する「今後の変動見込み」の指数です。(D)は追証（追加証拠金）の説明です。ロスカットは、追証を解消できないときなどに証券会社がポジションを強制的に決済することです。関連：6-8 早期割当・配当・ピン・リスク、6-6 満期日の流れ（日本）、6-5 追証とロスカット、4-10 VIXと日経平均VI

第2問　計算（8問・32点）

日経平均が51,000円のとき、日経225ミニオプション（乗数100）の権利行使価格52,000円のコールを745円で3枚買いました。SQ値が53,200円だった場合の損益はいくらですか。（4点）

  1. ＋45,500円
  2. ＋136,500円
  3. ＋360,000円
  4. ＋1,365,000円
解答と解説

正解：B（4点）　SQ値でITMなので自動的に権利行使され、1単位あたりの受取は 53,200−52,000＝1,200円です。支払ったプレミアム745円を引くと455円の利益。実額は 455×100（ミニの乗数）×3枚＝136,500円です。

(A)は1枚分、(C)はプレミアムを引き忘れた額（1,200×100×3）、(D)はラージ（乗数1,000）で計算した額です。損益分岐点は 52,000＋745＝52,745円で、SQ値はそれを455円上回っています。関連：2-4 取引単位（乗数）と実額の計算、3-7 日経225オプションでの実額例、6-6 満期日の流れ（日本）

株価80ドルの米国株で、権利行使価格75ドルのプットを1.22ドルで2枚売りました。満期に株価が70ドルで終わり、割当を受けて株を受け取ったので、すぐに70ドルで全株を売却しました。この一連の取引の損益はいくらですか（手数料は考えない）。（4点）

  1. ＋244ドル
  2. −756ドル
  3. −1,000ドル
  4. −1,244ドル
解答と解説

正解：B（4点）　米国の個別株オプションは現物受渡しです。プット2枚の割当で、75ドル×200株＝15,000ドルを払って株を買います。それを70ドルで売ると14,000ドルなので −1,000ドル。先に受け取ったプレミアム 1.22×100×2＝244ドルを足して、−756ドルです。

「割当→売却」は、差金決済で (75−70−1.22)×100×2＝−756ドル を受け払いしたのと同じ結果になります。(D)はプレミアムを受取ではなく支払として扱った誤りです。割当の時点で15,000ドルの資金が必要になる点も忘れないでください。関連：6-7 満期日の流れ（米国）、3-3 4つの基本ポジションの損益図

日経平均が41,380円、SQまで残り10日のとき、権利行使価格41,000円のコールが705円、同じ権利行使価格・同じ限月のプットが325円でした。2つの時間的価値について正しいものはどれですか。（4点）

  1. コールの時間的価値は705円、プットは325円
  2. コールの時間的価値は325円、プットも325円で、等しい
  3. コールの時間的価値は380円、プットは0円
  4. コールの時間的価値は325円、プットはOTMなので0円
解答と解説

正解：B（4点）　コールはITMで、本質的価値は 41,380−41,000＝380円。時間的価値は 705−380＝325円です。プットはOTMなので本質的価値は0で、プレミアム325円はすべて時間的価値です。

2つが等しいのは偶然ではありません。金利・配当を無視できるとき、プット・コール・パリティは「コール−プット＝原資産−K」なので、コール−(原資産−K)＝プット、つまり「ITMコールの時間的価値＝同じKのOTMプットの価格」になります。(D)は「OTMには価値がない」と誤解した答えで、OTMのプレミアムは全部が時間的価値です。関連：2-6 本質的価値と時間的価値、4-7 プット・コール・パリティ

米国株（株価60ドル）で、権利行使価格60ドル・残り3か月のヨーロピアン・タイプのプットが2.91ドルです。満期までに配当があり、その現在価値は0.50ドル、権利行使価格の現在価値は59.40ドルです。プット・コール・パリティから求めた、同じ条件のコールの理論価格はいくらですか。（4点）

  1. 2.41ドル
  2. 3.01ドル
  3. 3.51ドル
  4. 4.01ドル
解答と解説

正解：B（4点）　配当がある場合のパリティは「コール−プット＝原資産−配当の現在価値−権利行使価格の現在価値」です。コール＝2.91＋60−0.50−59.40＝3.01ドルです。

(A)は金利を無視して権利行使価格を60のまま使った答え（2.91＋60−0.50−60）、(C)は配当を無視した答え、(D)は配当を引かずに足してしまった答えです。配当があると権利落ちで株価が下がることが分かっているので、コールは安く、プットは高くなります。金利がプラスだと権利行使価格の現在価値が小さくなり、コールが高くなります。関連：4-7 プット・コール・パリティ、4-2 価格を決める6つの要素

日経平均が45,000円、日経225オプションのIVが24%です。1年を252取引日とすると、5取引日（約1週間）後の日経平均が約68%の確率で収まる範囲の目安（±1標準偏差）として、最も近いものはどれですか。（4点）

  1. 約44,320〜45,680円
  2. 約43,480〜46,520円
  3. 約41,600〜48,400円
  4. 約41,880〜48,120円
解答と解説

正解：B（4点）　期間の1σ＝IV×√(日数÷252)です。24%×√(5÷252)＝24%×0.1409≒3.38%。45,000円×3.38%≒1,521円なので、約43,480〜46,520円です。

(A)は1日分（24%÷√252≒1.51%、約680円）です。(C)は1日分を5倍した誤り（680×5≒3,400円）です。値動きの幅は日数に比例するのではなく、日数の平方根に比例して広がるので、5日なら1日の√5≒2.24倍です。(D)は1か月（21取引日、24%÷√12≒6.93%）の目安です。なお、現実の値動きは正規分布より裾が厚く、この範囲を外れることは理論より多く起こります。関連：4-8 ヒストリカル・ボラティリティとインプライド・ボラティリティ

日経225オプション（乗数1,000）で、デルタ0.45のコールを2枚買い、デルタ−0.30のプットを1枚売っています。ほかの条件が変わらず、日経平均が100円上がったとき、ポジション全体の損益の目安（デルタだけで計算）はいくらですか。（4点）

  1. 約＋6万円
  2. 約＋9万円
  3. 約＋12万円
  4. 約＋1.2万円
解答と解説

正解：C（4点）　グリークスは「符号×枚数×乗数」を掛けて足し算できます。コール買い：＋0.45×2×1,000＝＋900。プット売り：売りなので符号を反転し、−(−0.30)×1×1,000＝＋300。合計＋1,200（日経平均1,200倍分、先物ラージ1.2枚分）なので、100円の上昇で約＋12万円です。

(A)はプット売りのデルタを反転し忘れた答え（900−300＝600）、(B)はプット売りを入れ忘れた答え、(D)はミニの乗数100で計算した答えです。プットの売りは「下がらなければ得」なので、デルタはプラス（上昇で得）になります。関連：5-2 デルタ、5-8 ポジション全体のグリークスを合算する

米国株のATMコール（残り45日）を3枚買っています。1株あたりのセータは−0.04ドル/日、ベガは0.14ドル（IV 1ポイントあたり）です。4日後、株価は変わらず、IVは3ポイント上がりました。ポジション全体の損益の目安はいくらですか。（4点）

  1. −48ドル
  2. ＋26ドル
  3. ＋78ドル
  4. ＋126ドル
解答と解説

正解：C（4点）　1株あたり、時間の経過で −0.04×4日＝−0.16ドル、IVの上昇で ＋0.14×3＝＋0.42ドル、合計＋0.26ドルです。1枚は100株分、3枚なので 0.26×100×3＝＋78ドルです。

(A)はセータだけ、(D)はベガだけ、(B)は枚数（×3）を掛け忘れた答えです。株価が動かなくても、IVが上がれば買い手は得をし、時間が過ぎれば損をします。この2つの力の差し引きで損益が決まる、というのが「計器盤を合算して読む」考え方です。関連：5-4 セータ、5-5 ベガ、5-8 ポジション全体のグリークスを合算する

日経平均が50,000円のとき、日経225ミニオプション（乗数100）の権利行使価格48,000円のプットを480円で2枚売りました。SQ値が44,000円だった場合の損益はいくらですか。（4点）

  1. −352,000円
  2. −704,000円
  3. −800,000円
  4. −7,040,000円
