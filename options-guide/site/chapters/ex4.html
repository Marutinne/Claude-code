第7部　習熟度テスト

Lv.4 マスター試験

本書の全範囲（第1〜25章）を使う、総合ケーススタディ形式の試験です。4人の日本居住者のケースについて、戦略の設計、損益とグリークスの計算、管理ルール、最悪のシナリオ、税金、実行環境の選択までを通して考えます。80点以上で合格です。

この試験で確かめること
  • 目的（守る・稼ぐ・運用計画・自動化）から出発して、日本と米国のどちらの市場で、どの戦略を、何枚で組むかを決められるか
  • 実額（日経225ミニ×100、ラージ×1,000、米国株×100株）で損益・グリークス・ストレス時の損失を計算できるか
  • 国内の取引所取引の税金（20.315%の申告分離課税、損益通算の範囲、損失の3年繰越）を計算できるか。区分を確定できない取引について、確認の手順を説明できるか
  • 接続方式と証券会社を、「オプションを発注できるか」「日本居住者が使えるか」「PCを起動し続ける必要があるか」で選び、安全装置を設計できるか

試験の使い方

範囲第1章〜第25章（全範囲）。とくに第11〜21章（戦略と管理）、第23章（年利）、第24章（税制）、第25章（自動売買）を組み合わせて使います。
問題数と配点ケース4つ・全22問・100点満点（選択式18問×4点、記述式4問×7点）。各問の配点は問題文の末尾に書いてあります。
制限時間の目安120分。電卓は使ってかまいません。本文は見ずに解き、採点のときに解説のリンク先で確かめてください。
合格ライン80点以上（正答率80%）
採点方法選択式は正解なら4点、不正解は0点。記述式は「解答と解説」の模範解答と採点基準に沿って自己採点します（模範解答と同じ言葉である必要はなく、要素が数値・条件つきで書けていれば得点）。最後の採点表にケースごとの得点を書き込み、合計してください。
  1. ケースを読む
    各ケースの設定（数値例の枠）を読み、目的と制約に線を引く。
  2. 解く
    小問を順に解く。前の小問の答えを後の小問で使うことがある。
  3. 採点する
    全ケースを解き終えてから解説を開き、配点と採点基準どおりに採点する。
  4. 弱点の章に戻る
    下の対応表と、解説のリンク先の節を読み直す。
  5. 自分のケースを書く
    合格したら、自分の資金と目的で同じ形の計画書を作る。

不合格だった場合や、合格でも7割に届かないケースがあった場合は、次の章に戻って復習してください。

ケース1　日本株ポートフォリオ1,000万円を下落に備える（27点）

ケースの設定

会社員のAさん（45歳）は、特定口座で日本株のポートフォリオを時価1,000万円持っています。過去の値動きから、日経平均に対するベータ（連動度）は約1.1です。含み益が大きいので売りたくはありませんが、今後1〜2か月の急落に備えたいと考えています。オプションは初めてで、先物・オプション口座を開設しました。

  • 日経平均40,000円、IV 20%、次の満期まで残り30日
  • 日経225ミニオプション（乗数100）：38,000円プット 227円、42,000円コール 258円
  • ミニの限月は約1か月先までしかないので、ヘッジを続けるなら毎月買い直す（執筆時点）

ケース1（6問・27点）

ベータを考慮した持ち株の大きさに、プットの想定元本（日経平均×乗数）が最も近くなる枚数はどれですか。（4点）

  1. 日経225オプション（ラージ）のプット1枚
  2. 日経225ミニオプションのプット3枚
  3. 日経225ミニオプションのプット11枚
  4. 日経225ミニオプションのプット28枚
解答と解説

正解：B（4点）　ベータ調整後の持ち株は 1,000万円×1.1＝1,100万円（日経平均換算で 1,100万÷40,000＝275倍分）。ミニ1枚の想定元本は 40,000×100＝400万円なので、1,100万÷400万＝2.75、最も近いのは3枚です。

ラージ1枚は 40,000×1,000＝4,000万円分で、持ち株の約3.6倍になり過剰です。(D)は乗数を10として計算した誤りです。ベータは過去の値動きからの推定で、急落時に同じとは限らないうえ、個別株と日経平均の値動きのずれ（ベーシス・リスク）は残ります。関連：7-4 日経225ミニオプション、21-7 ポートフォリオ全体のグリークス管理（ベータ加重デルタ）、12-2 プロテクティブ・プット

ヘッジの費用について、正しいものはどれですか。（4点）

  1. 38,000円プット3枚は約6,800円。年間でも約8万円なので、費用は気にしなくてよい
  2. 38,000円プット3枚は約6.8万円。カラーにすれば費用はゼロになり、上昇の利益もそのまま得られる
  3. 38,000円プット3枚は約68万円で、1回で持ち株の約7%を払う
  4. 38,000円プット3枚は約6.8万円。毎月12回続けると約82万円（持ち株の約8%）。42,000円コールを3枚売ってカラーにすると差し引き約0.9万円の受取になるが、日経平均が42,000円を超えた分の上昇は、コールの損失で打ち消される
解答と解説

正解：D（4点）　プットは 227×100×3＝68,100円。毎月同じ条件で買い直すと 68,100×12＝817,200円で、持ち株の約8%です。5%外側（OTM）の保険でも、1年中かけ続けると期待リターンの大部分を食いかねない水準です。コールを売るカラーなら 258×100×3＝77,400円を受け取り、差し引き 9,300円の受取になりますが、42,000円より上の上昇はコールの売りで失います。

費用を抑える工夫として、ヘッジする期間を「急落が心配な期間」に限る、プット・スプレッドにする、カラーにする、などを比べます。なお、Aさんの持ち株は特定口座、ミニのコールは先物・オプション口座にあり、コールの売りは株で「カバー」されません（証拠金が別にかかり、税の区分も別）。関連：12-3 カラー、12-2 プロテクティブ・プット、19-7 日本で米国型の戦略を再現する代替手段

38,000円プット（残り30日）のデルタは約−0.18です。ヘッジを建てた直後のポジションについて、正しいものはどれですか。（4点）

  1. プット3枚のデルタは日経平均の約53倍分の売りで、持ち株（ベータ調整後で約275倍分の買い）の約2割しか打ち消していない。日経平均が下がるほどプットのデルタは大きくなり（ガンマ＋）、打ち消す割合が増える
  2. プットを3枚持てば、持ち株の値動きは常に完全に打ち消される
  3. プット3枚のデルタは約−5.3倍分なので、ほとんど効果がない
  4. 日経平均が下がるほどプットのデルタは小さくなり、ヘッジは効かなくなる
解答と解説

正解：A（4点）　−0.18×100×3＝−54、つまり日経平均の約53〜54倍分の売りです（デルタ−0.178で計算すると約53）。持ち株は275倍分の買いなので、建てた直後に打ち消しているのは約2割です。OTMのプットは「小さな下落には効かず、大きな下落で効いてくる」保険です。

プットの買いはガンマがプラスなので、下落するほどデルタが−0.5、−0.8…と大きくなり、ヘッジの効きが強まります。さらに急落時はIVが上がり（ベガ＋）、プットの価値が上乗せされます。逆に、日経平均が横ばいのままなら、セータの分だけ毎日価値が減ります。(C)は乗数100を掛け忘れた誤りです。関連：5-2 デルタ、5-3 ガンマ、5-8 ポジション全体のグリークスを合計する

最悪のシナリオとして、SQ値が32,000円（日経平均−20%）になり、持ち株がベータどおり22%下がった場合を考えます。次の図は、持ち株を日経平均換算（275倍分＝ミニ2.75枚分）で表し、38,000円プット3枚を加えたSQ時点の損益です。持ち株とプット（支払ったプレミアムを含む）を合わせた損益はいくらですか。（4点）

  1. 約−46.8万円
  2. 約−220万円
  3. 約−40万円
  4. 約+173万円
解答と解説

正解：A（4点）　持ち株は 1,000万×(−22%)＝−220万円。プットは (38,000−32,000)×100×3＝180万円の受取から、支払った68,100円を引いて +173.19万円。合計は −220万＋173.19万＝約−46.8万円（持ち株の約4.7%）です。

(B)はヘッジなし、(C)はプレミアムを引き忘れた答え、(D)はプットだけの損益です。図のとおり、この組み合わせの損失が最も大きくなるのは、SQ値がちょうど38,000円のときの約−61.8万円です（持ち株の−11%と、価値ゼロになったプットの費用）。「保険の免責」は、権利行使価格までの下落とプレミアムの合計だと分かります。急落がSQの前に起きた場合は、プットの時間的価値とIVの上昇も加わり、その時点で決済すれば受取はさらに大きくなりえます。関連：12-2 プロテクティブ・プット、21-6 ストレステストとシナリオ分析、3-5 損益図の足し算

ある年、Aさんのミニ・プットの損益（プレミアムの支払いとSQでの受取の合計）は+120万円になりました。同じ年、下落した持ち株の一部を特定口座で売却し、−150万円の譲渡損が出ました。ほかの所得や取引はないものとします。ミニ・プットの利益にかかる税額と扱いとして正しいものはどれですか（執筆時点、端数処理は考えない）。（4点）

  1. 0円。株の損失150万円と相殺して−30万円になり、翌年に繰り越す
  2. 243,780円。特定口座（源泉徴収あり）で自動的に納税されるので、確定申告は不要
  3. 243,780円。株の譲渡損とは通算できない。株の損失は株の区分の中で、確定申告すれば3年間繰り越せる
  4. 0円。株の損失を「先物取引に係る雑所得等」に繰り越して相殺できる
解答と解説

正解：C（4点）　日経225ミニオプションの損益は「先物取引に係る雑所得等」で、税率20.315%の申告分離課税です。120万円×20.315%＝243,780円。上場株式の譲渡損は「上場株式等の譲渡所得等」という別の箱なので、同じ20.315%でも通算できません（(A)(D)は誤り）。

先物・オプションは特定口座の対象外なので、自分で確定申告して納税します（(B)は誤り）。株の損失150万円は、株の箱の中で他の株の利益や申告分離を選んだ配当と通算するか、確定申告をして3年間繰り越します。ヘッジとして一体で考えていても、税金は箱ごとに計算される点が、日本でヘッジを組むときの落とし穴です。関連：24-2 国内の取引所取引、24-3 損益通算できる範囲と損失の3年繰越、24-4 特定口座の対象外

【記述式】Aさんが今後1年間、このヘッジを続けるための運用ルールを書きなさい。①ヘッジの費用の上限と手段の選び方、②買い直し（ロール）のタイミング、③急落してプットが大きく値上がりしたときの扱い、④持ち株とヘッジのずれの点検、⑤税と記録、の5項目を含めること。（7点）

解答と解説

模範解答

項目記入例
①費用の上限と手段ヘッジの費用は年間で持ち株の2%（20万円）までとする。38,000円プットを毎月買うと年約82万円で上限を大きく超えるので、急落が心配な期間（重要イベント前など）だけプットを買う、プット・スプレッド（例：38,000円買い／35,000円売り）で費用を下げる、上昇を一部あきらめてよい時期はカラーにする、のいずれかを選ぶ。
②買い直しミニは約1か月先までなので、毎月、最終取引日の数日前までに次の限月へ買い直す。最終取引日の日中取引の終了後は売買できないので、SQ持ち越しで保険が途切れないよう、次の限月を先に買ってから古い方を売る。
③急落時日経平均が権利行使価格を大きく下回り、プットの価値が当初の数倍になったら、半分を利益確定し、残りをより低い権利行使価格へロールダウンする（利益の一部を確定しつつ保険を残す）。持ち株を売るかどうかはヘッジと切り離して判断する。
④ずれの点検毎月、持ち株の時価とベータを見直して枚数を再計算する（1,100万円÷400万円＝2.75枚→3枚のように）。持ち株が日経平均と違う動きをする（ベーシス・リスク）ことを前提に、ヘッジで守れるのは市場全体の下落分だと理解しておく。
⑤税と記録ミニ・プットの損益は先物取引に係る雑所得等で、特定口座の対象外。年間の損益を集計して確定申告する（利益が出なかった年も、損失を繰り越すなら付表を付けて申告を続ける）。株の損益とは通算できないので、口座ごとに記録する。

採点基準（7点）　①費用の上限を金額か割合で決め、毎月プットを買う費用（年約82万円）と比べて手段を選んでいる（2点。上限だけなら1点）。②最終取引日より前に次の限月へ移る手順がある（1点）。③利益確定またはロールダウンの条件が書けている（1点）。④枚数の再計算とベーシス・リスクに触れている（1点）。⑤先物取引に係る雑所得等であること、株と通算できないこと、確定申告（繰越の付表）のうち2つに触れている（2点。1つなら1点）。関連：12-3 カラー、13-3 ベア・プット・スプレッド、7-3 限月・権利行使価格・SQ、20-5 ロール、24-3 損益通算と3年繰越

ケース2　米国株で毎月のインカムを狙う（31点）

ケースの設定

Bさん（38歳）は、米ドルの現金50,000ドルで、米国株のオプションを使って毎月のインカムを得たいと考えています。まずはキャッシュ・セキュアード・プットから始め、割り当てられたらカバード・コールに移る「ホイール」を計画しています。現在は、米国株オプションを扱う国内の証券会社Xで、手作業で注文しています。

  • 候補の銘柄XYZ：株価50ドル、IV 30%、残り30日
  • 47ドルのプット：0.58ドル（デルタ約−0.22）。1枚＝100株

ケース2（7問・31点）

この47プットを1枚売る場合の利回りについて、正しいものはどれですか。必要資金は、全額を現金で用意する4,700ドルとします。（4点）

  1. 30日で約1.2%、単純な年率換算で約15%。ただしこれは割当や急落の損失を含まない「表面の利回り」で、毎月同じ条件で売れるとも限らない
  2. 30日で約12.3%、単純な年率換算で約148%
  3. 30日で約1.2%、単純な年率換算で約15%。プットの売りは勝率が高いので、この年利はほぼ確保できる
  4. 必要資金は受取額の58ドルだけなので、利回りは100%
解答と解説

正解：A（4点）　58÷4,700≒1.23%（30日）、×12≒14.8%です。しかしこれは「何も起きなかった月」の数字で、割当や急落の損失を差し引く前の表面の利回りです。デルタ−0.22は「満期にITMになる確率の大まかな目安が2割強」という意味で、約5回に1回は割り当てられうる水準です。

年利は「分母」で何倍にも変わります。(D)は分母を受取額にした極端な例で、(B)は小数点の位置の誤りです。VRP（ボラティリティ・リスク・プレミアム）はありますが、その対価は急落時の大きな損失を引き受けることです。関連：23-1 「年利◯％」は分母しだい、23-2 単純年率換算の罠と複利、11-7 キャッシュ・セキュアード・プット

満期にXYZは45ドルに下がり、47プットが割り当てられて100株を受け取りました。Bさんは翌日、株価45ドルのときに50コール（残り30日、IV 30%）を0.22ドルで1枚売りました。その満期に株価は51ドルで、50コールが割り当てられて株を手放しました。「プレミアムを株の取得価額・譲渡価額に含める」考え方で、株の取得価額（100株分）と、プット売りからの一連の取引全体の利益の組み合わせとして正しいものはどれですか（手数料・円換算は考えない）。（4点）

  1. 取得価額4,700ドル、全体の利益300ドル
  2. 取得価額4,642ドル、全体の利益380ドル
  3. 取得価額4,642ドル、全体の利益358ドル
  4. 取得価額4,758ドル、全体の利益264ドル
解答と解説

正解：B（4点）　プットの割当で株を買ったので、取得価額＝47×100−58＝4,642ドル（1株46.42ドル）。コールの割当で株を売ったので、譲渡価額＝50×100＋22＝5,022ドル。利益は 5,022−4,642＝380ドル（＝株の値幅300ドル＋プレミアム58ドル＋22ドル）です。

割当まで行った取引では、プレミアムは株の損益に含まれ、「上場株式等の譲渡所得等」の箱で扱うのが基本の考え方です（反対売買で閉じたプレミアムはオプションの損益）。証券会社の報告書での扱いや円換算の方法は会社によって違いうるので、確認が必要です。なお、45ドルに下がった株に「取得価額46.42ドルより上」の50コールを売ったので、受取は0.22と小さくなっています。取得価額より下のコールを売ると、受取は増えますが、割り当てられたときに損失が確定します。関連：24-5 権利行使・割当で株を受け取ったとき、12-6 オプション・ホイール
