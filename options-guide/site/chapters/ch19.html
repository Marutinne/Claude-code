第3部　オプション戦略

第19章　戦略実行可否マップ ― 日本でできる戦略／米国でできる戦略 Lv.2〜3

第11〜18章で学んだ約60の戦略を、「日本の日経225オプション・ミニ・個別株オプション」と「米国の個別株・ETF・指数」のどこで実際に組めるかという視点で一覧にします。あわせて、日本では作れない米国型の戦略を、手元の商品でどこまで再現できるかを検討します。

この章で分かること
  • 「制度上できる」「流動性の面で現実的」「口座・証拠金の条件を満たせる」を分けて考える判定の基準と、◎○△×の意味
  • 全戦略×6つの市場（日経225ラージ／ミニ／日本の個別株／米国の個別株・ETF・指数）の可否一覧
  • 日本の個別株オプション、期先の限月、遠いOTMなどが「制度上は可能でも現実的でない」理由
  • カバード・コール、ホイール、プアマンズ・カバード・コール、0DTEを日本の商品で再現する代替手段と、その違い
  • 日本で始める人・米国で始める人それぞれの、無理のない出発点
注意

この章の判定は、執筆時点（2026年）の商品性と一般的な流動性をもとにした目安です。上場商品・満期の設定・取引レベルの区分・証拠金の計算方法は変わりますし、流動性は日によっても変わります。最新の情報はJPX（日本取引所グループ）、Cboeなど米国の取引所、各証券会社で確認してください。「◎」は「組みやすい」という意味であって、「安全」「おすすめ」という意味ではありません。売りを含む戦略は、受け取ったプレミアムをはるかに超える損失が出ることがあります。

19-1　判定の基準と記号の意味

ある戦略が「できるかどうか」は、次の3つの段階で考えます。1つでも満たさなければ、その市場では使えません。

  1. 制度上可能か
    必要な満期・権利行使価格が上場しているか。受渡し（現物か差金決済か）や権利行使のタイプが戦略の前提と合っているか。たとえばホイールは「割当で現物を受け取る」ことが前提なので、差金決済の日経225オプションでは形が作れません。
  2. 流動性の面で現実的か
    必要な限月・権利行使価格に気配があり、ビッドとアスクの差（スプレッド）がプレミアムに比べて小さいか。途中で手仕舞いできるか。
  3. 口座と証拠金の条件を満たせるか
    日本では「買いのみ」か「売建ても可」かの審査（6-1）、米国ではオプション取引レベル（8-6）。売りを含む戦略は証拠金が必要で、相場の急変で増えます。

税金の扱いも日米・商品で違いますが、「できる・できない」とは別の問題なので第24章で扱います（組み合わせる商品で損益を通算できない例は19-7で触れます）。

記号意味例
◎実用的。流動性があり、一般的な口座条件で個人が普通に組める日経225のブル・プット・スプレッド、SPYのカバード・コール
○可能だが条件付き。厳しい口座審査・大きな証拠金・銘柄や限月の選び方・代替手段（先物で代用など）が必要日経225のショート・ストラングル（売建ての承認と大きな証拠金）、先物で代用するカバード・コール
△制度上は可能だが、流動性やコストの面で現実的でない日本の個別株オプションのほぼすべて、日経225の1年先の限月を使う戦略
×不可。商品の仕組み上、その形が作れない日経225オプションでのホイール、SPXでのホイール

表の判定には、次の共通ルールを使っています。

  • 裸の売り（損失が無制限、または非常に大きい売り脚）を含む戦略は、流動性が十分でも最高で「○」とします。日本では売建ての承認と大きな証拠金、米国では最上位の取引レベル（多くの会社で「レベル4」など）が必要で、誰でも使えるわけではないためです。
  • 原資産と組み合わせる戦略（カバード・コールなど）は、日本の指数オプションでは日経225先物（ラージ・ミニ・マイクロ）で原資産を代用するため「○」とします。米国の指数も指数そのものを保有できないので、ETFや株式の保有に当てる「○」です。
  • 米国個別株は流動性の高い大型株を前提にしています。小型株や不人気銘柄では、ほとんどの戦略が「△」に下がります。脚が3本以上の戦略は、1本ずつのスプレッドが積み重なるため個別株では「○」とします。
  • 口座の欄は、日本は「買い」（買いのみの承認で可）か「売り」（売建ての承認が必要）、米国は8-6の一般的な例に合わせた「L1」（カバード・コール等）「L2」（買い）「L3」（スプレッド）「L4」（ネイキッドの売り）です。区分と名前は会社ごとに違います。
ここが重要

各章の早見表では、日本・米国それぞれ1つの欄に大まかな判定を書きました。本章は市場を6つに分けて判定し、記号の意味は上の4段階を全体の基準とします。各章の早見表の記号もこの意味で読んでください。必要な取引レベルは記号ではなく、口座の欄や備考で示します。

19-6　「制度上は可能」と「現実的」の違い

表の「△」の多くは、商品としては上場しているのに、個人が納得できる価格で売買できないものです。理由は主に次の5つです。

理由具体例なぜ困るか
商品全体の取引が少ない日本の有価証券オプション（7-6）、TOPIXオプションなど日経225以外の指数オプション（7-5）気配がない、スプレッドが広い、途中で手仕舞いする相手がいない。取り扱う証券会社も限られる
期先の限月日経225の3か月より先、特に1年先。ミニはそもそも約1か月先まで売買が期近の1〜2限月に集中する（16-8）。カレンダーやプアマンズ・カバード・コールの「期先の買い」が高くつく
ATMから遠い権利行使価格遠いOTM（アイアン・コンドルの外側、ラダーの外側）、深いITM（ガッツ、ゼブラ）板が薄く、理論価格から離れた値でしか約定しない。遠いOTMは「安いから」と成行で買うと割高になりやすい
時間帯日経225の夜間取引、米国の寄り付き直後参加者が少なくスプレッドが広がる（7-7）
脚の数クリスマス・ツリー（6枚）、ダブル・ダイアゴナル（4本）1本ずつのスプレッドと手数料が積み重なり、期待できる利益を食う
数値例

説明用の仮の数字です。日経平均50,000円のとき、残り30日のATMコールの気配がビッド700円・アスク710円なら、スプレッドは10円（プレミアムの約1.4%）で、ラージ1枚を買ってすぐ売ると失うのは10円×1,000＝1万円です。一方、1年先のATMコール（理論価格は約3,980円、IV20%）の気配がビッド3,800円・アスク4,200円なら、スプレッドは400円（約10%）で、買ってすぐ売るだけで40万円を失います。「制度上は1年先の限月がある」ことと、「1年先の限月で戦略を回せる」ことはまったく別です。

米国でも、SPYやSPXのATM付近はスプレッドが非常に狭い一方、小型株や遠い満期・遠い権利行使価格ではスプレッドが大きく広がります。表で米国個別株を「大型株が前提」としているのはこのためです。

実践テクニック

発注前に「スプレッド÷プレミアム」を計算し、自分の上限（たとえば5%）を決めておくと、△の領域に入り込むのを防げます。スプレッドが広いときは、成行ではなくビッドとアスクの中間付近に指値を置き、約定しなければ追いかけないのが基本です（6-3）。出来高と建玉（第2章）が少ない権利行使価格は、手仕舞いのときにもっと苦労します。

19-7　日本で米国型の戦略を再現する代替手段

米国で人気の戦略の多くは、「割当で現物の株を受け渡す」「LEAPSのような長い満期がある」「毎営業日に満期がある」という3つの前提に立っています。日経225オプションは差金決済で、期先は薄く、当日満期はありません。そこで、手元の商品で「形」を近づける方法を整理します。

米国型の戦略日本での代替米国版との違い
カバード・コール日経225先物（ラージ・ミニ・マイクロ）の買い＋コール売り。または日経平均連動ETF＋ミニ・コール売り差金決済なので現物は渡らない。先物は満期ごとのロールが必要で、レバレッジがある
キャッシュ・セキュアード・プット行使価格×乗数の現金を確保したプット売り割り当てられても指数は受け取らず、差額を現金で払って終わる
ホイールプット売りで損失が確定したら先物（またはETF）を買い、以後コールを売る自動では次の段階に進まない。実態はプット売りを続けているのに近い
プアマンズ・カバード・コール期近2限月のダイアゴナル、またはミニ・マイクロ先物＋コール売りLEAPSのような長い買い脚は作れない。先物版は損失が限定されない
0DTEミニ（水曜・金曜）やラージ（金曜）の週次の最終取引日に売買決済は翌朝のSQ値。最終取引日の引けから翌朝までのリスクが残る
決算プレイ日銀の金融政策決定会合、米国の雇用統計など指数全体のイベントで応用個別企業のイベントは日本では組めない。米国の個別株を使う
個別株のプロテクティブ・プット保有株に日経225プット（またはベア・プット・スプレッド）を当てる代用ヘッジ株と日経平均の動きのずれ（ベーシス・リスク）が残る

カバード・コール → 先物またはETF＋コール売り

最も素直な代替は、日経225ミニ先物（乗数100）を買い、同じ乗数のミニ・コールを売る形です（12-1）。ラージ先物1枚ならミニ・コール10枚、マイクロ先物（乗数10）10枚ならミニ・コール1枚が数量の目安です。

SQ値が52,000円なら、コールの損失(52,000−51,000)×100＝10万円を現金で支払い、先物の利益(52,000−50,000)×100＝20万円と受け取った7万2,000円で、合計＋17万2,000円です。米国のように株が引き取られて終わるのではなく、すべて現金の差額で清算されます。先物とオプションのSQが違う限月なら、先物はそのまま残り、先物価格と日経平均の差（ベーシス）の分だけ損益がずれます。

日経平均連動ETFを現物で持ち、ミニ・コールを売る形も考えられます。見た目は米国のカバード・コールに近いですが、次の3点が違います。

  • 現物は渡らない：コールがITMで終わっても、ETFはそのまま手元に残り、差額を現金で払います。ETFの値動きとSQ値も完全には一致しません。
  • 証拠金で相殺されにくい：日本の証拠金は先物・オプション口座の建玉で計算されるため、株式口座のETFはコール売りのリスクを打ち消すものとして扱われないのが一般的です。証拠金の上では裸のコール売りに近い扱いになります（ETFを代用有価証券として差し入れられるかを含め、証券会社で確認）。
  • 税の区分が違う：ETFの売買益は上場株式等の譲渡所得、オプションの損益は「先物取引に係る雑所得等」で、原則として両者の損益は通算できません。上昇してETFで利益・コールで損失が出ても、差し引きできない場合があります（第24章、国税庁で確認）。先物＋オプションなら同じ区分に入ります。

ホイール → そのままは再現できない

ホイールの核心は「プットを売る → 割当で株を受け取る → その株でコールを売る → 株が引き取られたらまたプット」という自動的な循環です。日経225オプションは差金決済なので、プットがITMで終わっても日経平均を受け取る段階が起こりません（7-10）。日本の個別株オプションなら制度上は受渡しがありますが、毎月売れる流動性がないのが実情です。

近い流れを作るなら、12-6の手順のとおり「SQでプット売りの損失が確定したら日経225ミニ先物（またはETF）を買い、以後はコールを売る」形になります。ただし、12-8で見たとおり「先物買い＋コール売り」は「プット売り」とほぼ同じ形です。つまり日本版ホイールの実態は、プット売りを休まず続けているのとほぼ同じで、下落時の損失は大きいままです。ホイールそのものをしたい場合は、米国の個別株・ETFオプションを扱う証券会社を使います（使える戦略は会社で違います。8-9）。

プアマンズ・カバード・コール → 期先の流動性の壁

プアマンズ・カバード・コールは、株の代わりに期先の深いITMコールを買って、少ない資金でカバード・コールに近い形を作る戦略です（16-6）。日経225ラージには1年を超える限月がありますが、売買がほとんどなく、図19-1のように「1年先×深いITM」は最も薄い領域です。ミニは約1か月先までしかないので、形そのものが作れません。

代わりの方法は2つです。1つは、次の限月のITMコールを買って週次のOTMコールを売る、期近2限月のダイアゴナル（16-4）。買い脚が短いので、LEAPSのように何度も売り重ねることはできません。もう1つはミニ・マイクロ先物を使うカバード・コールです。先物はもともと少ない証拠金で大きな金額を動かせるので「少ない資金で」の目的は果たせますが、最大損失が支払額までのプアマンズ・カバード・コールと違い、下落の損失は限定されません。

0DTE → ミニの週次満期の最終取引日

日本には、SPXやXSPのように当日の引けで決済される満期はありません。近い形は、ミニ（水曜・金曜が満期）やラージ（金曜が満期）の週次を、最終取引日（満期の前営業日。水曜満期なら火曜日）に売買することです。しかし決済は翌朝の構成銘柄の始値から計算するSQ値なので、最終取引日の取引終了から翌朝までに米国市場で起きた変動を、手仕舞いできないまま受けます（18-5）。なお、大阪取引所はミニの満期を毎営業日に設定する変更を発表しており、執筆時点では2027年4月の実施が予定されています（7-4。JPXで確認）。

19-8　読者タイプ別のおすすめ出発点

どちらの市場でも、「損失が支払額までの買い → 損失が限定された売り（スプレッド） → 原資産や時間差と組む戦略 → 裸の売りや0DTE」の順に1段ずつ進むのが基本です。投資の推奨ではなく、学習の順番として示します。

日本で始める人（日経225オプション）

  1. 先物・オプション口座を「買いのみ」で開く
    取引時間、SQ、最終取引日の流れを確認します（6-1）。
  2. ミニで少額の買い
    1枚500万円分（日経平均50,000円の場合）で、ラージの10分の1。ロング・プットで手持ちの日本株の保険を試すなど。
  3. 売建ての承認を受け、垂直スプレッドへ
    ブル・プット・スプレッドなど、損失が幅までの形で「売り」を学びます（13-4）。
  4. アイアン・コンドル、バタフライ
    期近・ATM付近で組める◎の戦略。遠いOTMの板の薄さに注意します。
  5. 先物と組む・時間差を使う
    ミニ先物＋コール売り、カラー、期近2限月のカレンダーへ。
  6. 裸の売りは最後に、少ない枚数で
    過去の急落の幅でストレステストをしてから枚数を決めます（第21章）。

米国で始める人（米国の個別株・ETF・指数）

  1. 証券会社と「できる戦略」を確認する
    米国オプションを扱う国内の会社は限られ、使える戦略も違います。為替・時差・確定申告の手間も比べます（8-9）。
  2. L1〜L2：カバード・コールや少額の買い
    保有する株・ETFでのカバード・コールや買いで、注文から満期処理まで一通り経験します。
  3. L3：スプレッドへ
    SPYやXSPのような流動性が高く1枚が小さめの銘柄で。指数は早期割当がありません（8-4）。
  4. ホイール、プアマンズ・カバード・コール、カレンダー
    米国ならではの戦略。ホイールは1枚で100株分の資金が必要です。
  5. 0DTEやL4の裸の売りは最後に
    損失が短時間で受取額の数倍になりえます。XSPの1枚のスプレッドなど小さい形から（18-5）。

まとめ

  • 戦略が使えるかは「制度上可能か」「流動性の面で現実的か」「口座・証拠金の条件を満たせるか」の3段階で判断する。税の違いは第24章で扱う。
  • 日経225オプション（ラージ・ミニ）では、垂直スプレッド、ストラドル・ストラングル、バタフライ、アイアン・コンドルなど「期近・ATM付近」で組める戦略はほぼ◎。裸の売りを含むものは売建ての承認と証拠金が必要で○。
  • 日本の個別株オプションは、制度上ほとんどの戦略が組めるが、流動性の面でほぼすべて△。期先の限月、遠いOTM・深いITM、夜間取引、脚の多い戦略も△になりやすい。
  • 差金決済の日経225オプションとSPXなどの米国指数では、割当で現物を受け取るホイールは×。米国のホイールやカバード・コールは個別株・ETFで行うのが自然。
  • 日本での代替：カバード・コールは先物（またはETF）＋コール売り、ホイールは損失確定後に先物を買う流れ（実態はプット売りの継続に近い）、プアマンズ・カバード・コールは期近2限月のダイアゴナルか先物版、0DTEはミニ週次の最終取引日（決済は翌朝のSQ値）。
  • ETF＋日経225コール売りは、証拠金で相殺されにくく、税の区分も違うので、米国のカバード・コールと同じではない。
  • 日本・米国のどちらから始めても、買い → 限定リスクの売り → 原資産や時間差 → 裸の売り・0DTE の順に進む。

確認テスト

日本の有価証券オプション（個別株オプション）でカバード・コールを組むことについて、本章の記号で最も適切なものはどれですか。

  1. ◎：流動性が高く、個人が普通に組める
  2. ○：売建ての承認があれば問題なく組める
  3. △：制度上は組めるが、流動性の面で現実的でない
  4. ×：個別株オプションは差金決済なので組めない
解答と解説

正解：C　有価証券オプションは現物受渡しで、制度上はカバード・コールもホイールも組めます（Dは誤り）。しかし多くの銘柄・権利行使価格で気配がほとんどなく、スプレッドも広いので、実際に回すのは難しいのが実情です（7-6）。

日経225オプションで「ホイール」がそのまま作れない最大の理由はどれですか。

  1. 日経225オプションにはプットが上場していないから
  2. 差金決済なので、プットが割り当てられても日経平均（現物）を受け取る段階が起こらないから
  3. 日経225オプションはアメリカン・タイプで、いつ割り当てられるか分からないから
  4. 日経225オプションではコールを売ることができないから
解答と解説

正解：B　ホイールは割当で現物を受け取り、それを使ってコールを売る循環です。日経225オプションはヨーロピアン・タイプの差金決済で、ITMで終わっても差額を現金で払うだけです。同じ理由で、差金決済のSPXでもホイールは×です。

日経平均連動ETFを株式口座で保有し、日経225ミニ・コールを1枚売りました。米国の「株＋コール売り」のカバード・コールとの違いとして正しくないものはどれですか。

  1. コールがITMで終わっても、ETFは引き取られず、差額を現金で支払う
  2. 証拠金の計算では、ETFがコール売りのリスクと相殺されないのが一般的である
  3. ETFの売買益とオプションの損益は、原則として税の区分が違い通算できない
  4. コールがITMで終わると、保有しているETFが自動的に権利行使価格で売却される
解答と解説

正解：D　日経225ミニオプションは差金決済なので、ETFが自動で売られることはありません（Aのとおり差額の現金払い）。A〜Cはいずれも米国のカバード・コールとの違いとして正しい説明です。税の扱いの詳細は第24章で確認してください。

説明用の数字です。日経225オプション（ラージ）の1年先の限月で、ATMコールの気配がビッド3,800円・アスク4,200円でした。アスクで1枚買い、直後にビッドで1枚売ると、損失はいくらですか（手数料は除く）。

  1. 400円
  2. 4万円
  3. 40万円
  4. 400万円
解答と解説

正解：C　（4,200−3,800）×1,000＝40万円です。期近のATMでスプレッドが10円なら1万円で済むところ、期先では40倍になります。これが、プアマンズ・カバード・コールやカレンダーが日本では「制度上は可能でも現実的でない」理由です。

日経225ミニオプションの水曜日満期の限月を「0DTEのように」使いたいと考えました。正しい説明はどれですか。

  1. 水曜日の日中取引の終値で決済されるので、SPXの0DTEと同じである
  2. 最終取引日は火曜日で、決済は水曜日の朝の構成銘柄の始値から計算されるSQ値で行われる
  3. 最終取引日は水曜日の夜間取引の終了時である
  4. ミニオプションはアメリカン・タイプなので、火曜日の夜に割り当てられることがある
解答と解説

正解：B　満期の前営業日が最終取引日なので、水曜満期なら火曜日です。決済は水曜朝のSQ値なので、火曜の取引終了から水曜朝までの米国市場などの変動を、手仕舞いできないまま受けます。ミニはヨーロピアン・タイプで、途中の割当はありません（7-4、18-5）。

日本で「少ない資金でカバード・コールに近い形を作りたい」（米国のプアマンズ・カバード・コールの目的）と考えた人への説明として、最も適切なものはどれですか。

  1. 日経225ミニオプションの1年先のコールを買えば、米国と同じように組める
  2. 日経225ミニ先物＋ミニ・コール売りなら少ない証拠金で組めるが、最大損失が支払額までに限られるプアマンズ・カバード・コールと違い、下落の損失は限定されない
  3. 日本の個別株オプションのLEAPSを使うのが最も流動性が高い
  4. 日経225オプションではコールの売りができないので、どの方法でも不可能である
解答と解説

正解：B　ミニは約1か月先までしか満期がないのでAは作れません。先物はもともとレバレッジがあるので「少ない資金で」の目的は果たせますが、損失の形が違います。もう1つの代替は期近2限月のダイアゴナルで、こちらは損失が支払額までに限られますが、買い脚の期間が短くなります。
